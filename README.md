# Pedanyan Design School

The initial codebase for [school.pedanyan.com](https://school.pedanyan.com): a conversion-focused public site and student learning cabinet for Pedanyan Design School.

```bash
npm install
npm run dev
```

The app runs with complete demo data when Supabase credentials are absent. See [AI_CONTEXT_SCHOOL.md](./AI_CONTEXT_SCHOOL.md) for product decisions and [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md) for backend and hosting setup.
