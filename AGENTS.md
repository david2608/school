# Repository Instructions

## Pedanyan brand voice

All user-visible content must follow the system in `brand/`.

Use `pedanyan-brand-voice` when creating marketing copy, course descriptions, headings, About or Method content, onboarding, emails, testimonials, or public website copy.

Use `pedanyan-content-editor` when materially rewriting existing copy, reviewing a completed page, or performing content QA.

For simple functional UI text, follow `brand/CONTENT_RULES.md` without over-stylizing it.

Read `brand/FACTS.md` before making factual claims. Never silently invent facts.
